수업 전에 하는 일

한 번만 하면 학기 내내 그대로 씁니다. 5분이면 끝납니다.

  1. 선생님 화면에서 구글 로그인

    주소 끝이 /teacher.html 입니다. 처음 한 번만 계정을 고르면 다음부터는 바로 들어갑니다.

  2. 학교 책장 만들기

    학교 이름, 성함, 책장 이름 세 칸만 채우면 SEO-2026-4K7Q 모양의 코드가 자동으로 나옵니다. 앞 세 글자는 학교 이름에서 따옵니다. 학년별로 나누고 싶으면 “책장 하나 더 만들기”로 여러 개 만드세요.

  3. 학생에게 코드 알려 주기

    QR 보기로 띄우거나 인쇄해 교실에 붙입니다. 주소 복사로 학급 게시판에 올려도 됩니다. 코드만 칠판에 적어도 됩니다.

수업 중

1차시 시연과 학생 제출을 같은 화면에서 합니다.

시연할 때

주소 끝에 ?demo=1 을 붙이면 미리보기 책장이 열립니다. 예시 책 네 권이 이미 꽂혀 있어서 빈 책장을 보여 주지 않아도 됩니다. 이 모드는 그 컴퓨터에만 저장되고 실제 데이터에 영향을 주지 않습니다.

미리보기 책장
sci-shelf.netlify.app/shelf.html?code=DEMO-2026-BOOK&demo=1

책을 누르면 앞표지가 왼쪽으로 열리면서 펼쳐집니다. 왼쪽 면은 만든 이유와 사용 방법, 오른쪽 면은 시뮬레이션입니다. 화살표 키로 다음 책, Esc 로 닫기가 됩니다. 휴대폰에서는 아래에서 시트가 올라옵니다.

학생에게 시킬 때

학생은 로그인하지 않습니다. 책장 화면 오른쪽 아래 “산출물 제출하기”를 누르고 아홉 칸을 채우면 끝입니다. 적는 항목은 학년·반, 모둠명, 책 제목, 개발자의 의도, 시뮬레이션 링크, 사용 방법, 관련 과학 개념, 모둠원 이름, 표지입니다.

작품 자체는 이 사이트에 올리지 않습니다. 제미나이·캔바·러버블 어디서 만들었든 공유 링크만 받습니다. 링크는 https:// 로 시작해야 접수됩니다.

다른 선생님도 쓰게 하려면

승인한 계정만 책장을 만들 수 있습니다. 선생님이 직접 신청하고, 관리자는 단추 하나로 승인합니다.

  1. 선생님 화면 주소를 알려 줍니다

    처음 온 선생님은 로그인 없이 둘러보기로 예시 책장을 눌러 볼 수 있습니다. docs/teacher-guide.md 안내문을 함께 보내도 좋습니다.

  2. 그 선생님이 구글로 로그인해 “사용 신청”을 냅니다

    학교 이름과 성함을 적습니다. 연락처는 적어도 되고 안 적어도 됩니다. 학교 계정이든 개인 계정이든 상관없습니다.

  3. 선생님 화면 맨 아래 “관리자 · 선생님 승인”의 “사용 신청” 표에서 승인을 누릅니다

    누르는 순간 그 선생님 화면이 저절로 책장 만들기로 넘어갑니다. 신청 없이 주소만 받아서 “이메일로 직접 승인”에 넣어도 됩니다.

궁금한 것답
승인 전에 로그인하면“사용 신청” 서식이 뜹니다. 신청한 뒤에는 “접수되었습니다” 화면이 뜹니다
새 신청이 온 것은 어떻게 아나요알림 메일은 없습니다. 선생님 화면을 열면 “사용 신청 N건”으로 보입니다
신청서의 연락처는승인하거나 거절하는 순간 지워집니다. 명단에는 이메일·학교·성함만 남습니다
승인한 뒤에는새로 고치지 않아도 그 선생님 화면이 바로 책장 만들기로 넘어갑니다
서로의 책장이 보이나요아니요. 각자 자기 책장만 봅니다
학생도 계정이 필요한가요아니요. 코드만 있으면 됩니다
승인을 취소하면새 책장을 못 만듭니다. 이미 만든 책장은 그대로 씁니다
비용은무료 한도 안입니다. 하루 읽기 5만 건, 쓰기 2만 건

관리자 계정은 Firestore의 admins 문서로 정해집니다. 코드에는 이메일을 적지 않았습니다. 관리자를 바꾸거나 늘리려면 Firebase 콘솔에서 admins 컬렉션에 이메일을 문서 이름으로 하나 더 만들면 됩니다.

관리자는 다른 학교 책장의 이름을 고치거나 지울 수 있고, 올라온 책을 숨길 수 있습니다. 다만 모둠원 이름은 관리자도 읽지 못합니다. 그 책장을 만든 선생님만 봅니다.

한 책장을 두 선생님이 함께 관리하는 기능은 아직 없습니다.

휴대폰 홈 화면에 앱으로 넣기

앱 장터에 올리지 않아도, 홈 화면에 아이콘을 두고 주소창 없이 전체 화면으로 엽니다.

기기방법
안드로이드 (크롬·삼성 인터넷)책장이나 선생님 화면을 연 뒤 메뉴 → 앱 설치 또는 홈 화면에 추가
아이폰·아이패드 (사파리)공유 단추 → 홈 화면에 추가

학생 화면에서 넣으면 “과학 책장”, 선생님 화면에서 넣으면 “책장 관리”라는 앱이 됩니다. 학생용 앱은 마지막에 본 책장을 기억해 아이콘을 누르면 바로 엽니다. 아이폰은 앱 안의 저장 공간이 사파리와 따로라서, 넣은 뒤 처음 한 번은 책장 코드를 다시 넣어야 합니다.

화면을 휴대폰에 저장해 두지 않으므로 인터넷이 있어야 열립니다. 대신 사이트를 고치면 앱에도 바로 반영됩니다.

공개되는 것과 안 되는 것

학생 이름은 설계 단계부터 공개 화면에 나오지 않게 막아 두었습니다.

항목공개 책장선생님 화면

책 제목·의도·사용 방법·개념보임보임
작품 링크보임보임

화면에서 가리는 정도가 아니라 저장소 규칙으로 막혀 있습니다. 주소를 직접 두드려도 승인 전 제출물과 모둠원 이름은 거부됩니다. 다른 선생님이 남의 책장을 고치는 것도 막힙니다.

코드가 밖으로 새면 선생님 화면에서 코드 재발급을 누르세요. 예전 코드로는 더 이상 제출할 수 없고, 이미 꽂힌 책은 그대로 남습니다.

.firebaserc 에 프로젝트가 고정되어 있어 --project 는 붙이지 않아도 됩니다. --only firestore:rules 없이 실행하면 쓰지 않는 Storage까지 올리려다 실패합니다.

표지 캡처 업로드를 켜고 싶을 때

Firebase 콘솔에서 Storage를 시작한 뒤 assets/firebase-config.js 의 coverUpload 를 true 로 바꾸고, storage.rules 를 함께 배포하면 제출 폼에 업로드 칸이 다시 나타납니다. 최근 만든 프로젝트는 Storage를 켤 때 결제 등록을 요구할 수 있습니다.

Netlify로 학생용·교사용 주소를 따로 두려면

저장소 하나를 Netlify 사이트 두 개에 연결합니다. 파일은 같고 첫 화면만 다릅니다. GitHub에 올리면 두 사이트가 함께 새로 배포됩니다.

  1. Netlify에 GitHub 계정으로 가입하고 이 저장소를 사이트로 추가합니다

    Add new site → Import an existing project → GitHub → science-inquiry-hub. 빌드 설정은 netlify.toml 이 정하므로 그대로 두고 Deploy를 누릅니다.

  2. 사이트 이름과 역할을 정합니다

    Site configuration → Site details → Change site name (예: sci-shelf). Environment variables 에 SITE_ROLE = student 를 넣고 Deploys → Trigger deploy. 이제 그 주소의 첫 화면이 공개 책장입니다.

  3. 같은 저장소로 사이트를 하나 더 만들고 SITE_ROLE = teacher

    이 주소는 첫 화면이 선생님 화면입니다. 지금 쓰는 주소: sci-teacher.netlify.app

  4. Firebase 승인된 도메인에 교사용 주소를 넣습니다

    Firebase 콘솔 → Authentication → Settings → 승인된 도메인 → 도메인 추가. 학생용은 로그인이 없어 넣지 않아도 됩니다.

  5. assets/site-config.js 에 학생용 주소를 적고 올립니다

    studentLink: "https://sci-shelf.netlify.app/c/{code}" 로 적혀 있어 선생님 화면의 주소 복사와 QR이 이 짧은 주소로 나갑니다. "학생 화면 보기" 옆 패널은 자기 사이트의 책장을 띄우므로 학생용 사이트가 잠시 멈춰도 미리보기는 됩니다.

Netlify에서만 되는 짧은 주소실제로 열리는 것
/c/책장코드공개 책장 (QR·칠판용)
/s/책장코드제출 폼
/shelf · /teacher · /submit · /hub각 화면. 탐구 앱 허브는 /hub

GitHub Pages 주소는 그대로 살아 있습니다. 두 곳이 같은 Firebase를 보므로 어느 주소로 들어와도 같은 책장이 보입니다.

  • 표지 캡처 업로드는 꺼 둔 상태입니다. Storage를 쓰지 않습니다.
  • 제출 횟수를 제한하는 장치는 없습니다. 코드를 아는 사람은 제출할 수 있고, 승인 전 비공개로 막습니다.
다른 선생님께 나눠 줄 한 쪽짜리 안내는 저장소의 docs/teacher-guide.md 에 있습니다. 이 노트는 2026년 9월 16일 기준입니다.
