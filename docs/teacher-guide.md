# 산출물 책장 — 선생님 한 쪽 안내

학생 모둠이 만든 과학 시뮬레이션을 학교 책장에 모아 두는 곳입니다.
선생님이 하실 일은 **네 가지**뿐입니다. 설정 파일이나 콘솔은 만지지 않으셔도 됩니다.

주소: **https://raph-alpaca.github.io/science-inquiry-hub/teacher.html**

---

## 0. 먼저 사용 승인을 받으세요

**쓰실 구글 계정 주소를 관리 선생님께 알려 주세요.** 승인된 계정만 책장을 만들 수 있습니다.
승인 전에 로그인하면 "아직 사용 승인이 되지 않은 계정입니다" 화면이 뜹니다. 그 화면에 보이는
주소를 그대로 알려 주시면 됩니다.

## 1. 구글로 로그인하기

위 주소를 열고 **구글로 로그인**을 누릅니다. 학교 구글 계정이든 개인 계정이든 괜찮지만,
승인받은 계정과 같아야 합니다.

## 2. 학교 책장 만들기

처음 로그인하면 칸 세 개가 나옵니다.

| 칸 | 예시 |
|---|---|
| 학교 이름 | 서울○○중학교 |
| 선생님 성함 | 김선생 |
| 책장 이름 | 2학년 책장 |

**책장 만들기**를 누르면 `SEO-2026-4K7Q` 같은 **책장 코드**가 자동으로 나옵니다.
학년별로 따로 쓰고 싶으면 **+ 책장 하나 더 만들기**로 여러 개 만들 수 있습니다.

## 3. 학생에게 코드 알려 주기

책장 카드의 단추를 씁니다.

- **QR 보기** → 화면에 띄우거나 **인쇄하기**로 뽑아서 교실에 붙입니다.
- **주소 복사** → 학급 게시판이나 메신저에 붙여넣습니다.
- **코드 복사** → 칠판에 적어 줍니다.

학생에게는 이렇게 말해 주시면 됩니다.

> "QR을 찍거나 주소로 들어가서, 오른쪽 아래 **산출물 제출하기**를 누르고
> 모둠 작품 링크와 설명을 적어 내세요. 선생님이 확인하면 책장에 꽂힙니다."

학생은 **로그인하지 않습니다.** 코드만 있으면 제출할 수 있습니다.

## 4. 제출된 책 승인하기

선생님 화면에 **승인 대기**로 쌓입니다.

- 한 권씩 보려면 각 줄의 **승인**
- 한꺼번에 하려면 **대기 중인 N권 모두 승인**
- 내용을 고치려면 **수정**, 잠시 내리려면 **숨김**

승인하는 순간 공개 책장에 꽂힙니다.

---

## 꼭 아셔야 할 것

- **학생 이름은 공개 화면에 절대 나오지 않습니다.** 모둠원 이름은 이 선생님 화면에서만 보입니다.
- 승인 전에는 아무에게도 보이지 않습니다.
- 학생 작품은 이 사이트에 올리는 것이 아니라 **공유 링크만** 받습니다. 제미나이·캔바·러버블 어디서 만들어도 됩니다.
- 맨 윗줄 **선생님 예시 서가**(9권)는 모든 학교에 똑같이 보이는 참고 예시입니다.
- 마음에 드는 학생 작품은 **수정 → "우리 학교 예시로 올리기"**로 위쪽 칸에 꽂을 수 있습니다.

## 자주 묻는 것

**Q. 다른 반 학생이 장난으로 제출하면요?**
승인 전에는 공개되지 않습니다. 그냥 두면 책장에 꽂히지 않고, **숨김**을 누르면 목록에서도 내려갑니다.

**Q. 학교 이름을 잘못 적었어요.**
책장 카드의 **책장 설정**에서 학교 이름, 성함, 책장 이름을 고칠 수 있습니다. 코드는 그대로 유지됩니다.
책장을 통째로 지우는 것도 같은 곳에서 합니다. 안에 든 책과 모둠원 이름까지 함께 지워집니다.

**Q. 코드가 밖으로 새어 나갔어요.**
**코드 재발급**을 누르면 새 코드가 나옵니다. 예전 코드로는 더 이상 제출할 수 없습니다. (이미 꽂힌 책은 그대로 남습니다.)

**Q. 학생 작품 링크를 눌러도 책장 안에서 안 열려요.**
바깥 사이트가 다른 화면 안에서 열리는 것을 막아 둔 경우입니다. **시뮬레이션 열기**를 누르면 새 창에서 열립니다.

**Q. 제출 내용을 모아서 평가하고 싶어요.**
**CSV 내보내기**를 누르면 엑셀에서 열 수 있는 파일이 내려받아집니다. 모둠원 이름도 들어 있습니다.

**Q. 학생이 링크를 잘못 냈어요.**
**수정**에서 링크를 고치거나, 아래쪽 **이 책 삭제**로 지울 수 있습니다.

## 학생용 안내 (그대로 복사해 쓰세요)

```
우리 반 과학 산출물 책장
1. 아래 주소로 들어갑니다 (또는 교실 QR을 찍습니다)
   https://raph-alpaca.github.io/science-inquiry-hub/shelf.html?code=우리반코드
2. 오른쪽 아래 "산출물 제출하기"를 누릅니다
3. 학년·반·모둠명, 책 제목, 만든 이유, 작품 링크, 사용 방법,
   관련 과학 개념, 모둠원 이름을 적습니다
4. 표지를 고르고 공개 동의에 체크한 뒤 "책장에 꽂기"를 누릅니다
   → 선생님이 확인하면 책장에 꽂힙니다
※ 모둠원 이름은 책장에 공개되지 않고 선생님만 봅니다
```
