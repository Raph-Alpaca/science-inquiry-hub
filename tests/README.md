# 검사

사이트를 돌리는 데는 필요 없고, 고친 뒤 깨진 곳이 없는지 볼 때 씁니다.

```bash
cd tests
npm install
npm run install-browser     # 처음 한 번, Playwright 용 Chromium
npm test                    # 화면 검사 + 규칙 검사 + 로그인·승인 검사
```

| 명령 | 내용 |
|---|---|
| `npm run app` | 탐구 앱 12쪽을 1920·1280·380 에서 열고 콘솔 오류·가로 넘침·조작을 확인. 과학 계산과 화면 표현(전등 위치, 입자 겹침, 빛 섞기 비율, 반응식 계수비, 기체 예측, 자유 낙하 등)도 점검 (72항목) |
| `npm run sensor` | 실시간 센서 모드. 가상 센서로 네 앱을 돌려 보고(자유 낙하 분석 포함), 가짜 블루투스에 업체별 패킷을 흘려 어댑터 4종(PASCO·사이언스큐브·EZMaker·Vernier)의 판별·해석을 확인한다. 미지원 브라우저, CSV, 외부 전송 0건 포함 (59항목) |
| `npm run media` | 소리 측정실·빛의 색 측정기. 진동수·색 계산, 크롬 가짜 마이크·카메라에 만든 WAV·Y4M 을 흘려 실제 입력 경로 확인, 권한 거부·미지원, 색 화면, CSV, 빠르게 켜고 끄기, 외부 전송 0건 (57항목) |
| `npm run shelf` | 책장·제출·선생님 화면을 데모 모드로 끝까지 돌려 봄. 지우기 확인창·되돌리기, 책 표지 글자 잘림 포함 (136항목) |
| `npm run peek` | 선생님 화면의 "학생 화면 보기" 옆 패널 (39항목) |
| `npm run code` | 책장 코드 입력 칸 (22항목) |
| `npm run rules` | Firestore·Storage 보안 규칙을 에뮬레이터에서 검증 (61항목). Java 17 이상 필요 |
| `npm run login` | 선생님 화면의 로그인·승인 흐름을 에뮬레이터(auth + firestore)로 끝까지 돌려 봄. 연결이 잠시 끊긴 상황, 승인 취소 되돌리기도 재현한다 (24항목). Java 17 이상 필요 |

스크린샷은 `shots/` 에 남습니다. 모두 데모 모드와 에뮬레이터만 쓰므로 실제 데이터에는 손대지 않습니다.
