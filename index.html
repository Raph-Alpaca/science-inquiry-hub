과학탐구 앱 허브

  1. 탐구 질문 읽기앱 맨 위의 질문부터
  2. 예측 적기조작하기 전에 기록장에
  3. 조작하며 관찰 → 설명 적기숫자와 그래프를 근거로
  4. "이 앱을 만든 프롬프트" 열어 보기내 앱을 설계할 때 참고

수업에서의 자리

  1. 1차시 — 이 허브의 앱을 체험하고, 강의식 수업과 무엇이 달랐는지 기록
  2. 2차시 — 모둠 주제 선정, 앱 기획서(PRD)와 프롬프트 합의 (토크로그)
  3. 3차시 — 만든 앱 실행, 오류·과학 개념 대조, 수정 프롬프트 (토크로그)
  4. 4차시 — 개발자 회의 방식의 상호 피드백
  5. 5차시 — 디지털 교과서 페이지 형태로 산출물 정리·공유

데이터 소스

모든 앱은 시뮬레이션으로 동작합니다. 단열 재료 비교·가열 곡선·에너지 전환(진자)·이슬점 앱은 상단의 데이터 선택 칸에서 실시간 센서를 고르면 무선 온도·힘 센서(Web Bluetooth, 크롬북·안드로이드·윈도우의 Chrome/Edge)를 연결해 실측값을 이론 곡선 위에 겹쳐 볼 수 있습니다. 측정값은 기기 밖으로 전송하지 않습니다. 소리 측정실과 빛의 색 측정기는 따로 센서 없이 휴대폰·태블릿의 마이크와 카메라로 잽니다(https 주소에서 권한 허용 필요, 녹음·촬영 저장 없음). 나머지 앱의 센서는 준비 중입니다.

각 앱의 "이 앱을 만든 프롬프트"는 2차시 프롬프트 설계의 참고 예시입니다.
