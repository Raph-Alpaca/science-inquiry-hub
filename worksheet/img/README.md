# 학생 활동지 안내 그림

이 폴더에 아래 이름으로 그림 파일을 넣으면, 학생 활동지의 "○○ 이미지 추가하세요" 칸이 그 그림으로 바뀝니다.
코드는 고치지 않아도 됩니다. 파일은 `.png` 또는 `.jpg` 로 저장하고, 이름은 아래와 똑같이 맞춰 주세요.

| 파일 이름 | 차시 | 들어가는 자리 | 활동지 version2 의 쪽 |
|---|---|---|---|
| `n2-1.png` | 2차시 | 프롬프트 입력하기 ① 제미나이 접속, + 버튼 클릭하여 Canvas 기능 켜기 | 3쪽 위 |
| `n2-2.png` | 2차시 | 프롬프트 입력하기 ② 모델 설정, 입력 창에 프롬프트 입력 및 제출 | 3쪽 아래 |
| `n3-1.png` | 3차시 | 수정 프롬프트 입력하기 | 5쪽 |
| `n3-2.png` | 3차시 | 공유용 링크 생성하기 ① 공유 클릭 | 6쪽 ① |
| `n3-3.png` | 3차시 | 공유용 링크 생성하기 ② 공유 클릭 | 6쪽 ② |
| `n3-4.png` | 3차시 | 공유용 링크 생성하기 ③ 링크 복사 | 6쪽 ③ |
| `n4-1.png` | 4차시 | 출판 의뢰하는 방법 ① 책장에서 '출판 의뢰하기' 클릭 | 7쪽 ③ |
| `n4-2.png` | 4차시 | 출판 의뢰하는 방법 ② 출판 의뢰서 작성 | 7쪽 ④ 왼쪽 |
| `n4-3.png` | 4차시 | 출판 의뢰하는 방법 ③ 책 표지의 그림과 색 선택 | 7쪽 ④ 오른쪽 |

- 가로 1200px 이상인 화면 캡처가 알맞습니다. 세로 길이는 그림에 맞춰 늘어나고, 활동지에서 그림을 누르면 새 창에서 크게 보입니다.
- 지금 들어 있는 그림: `n2-*`, `n3-1` 은 직접 찍은 캡처, `n3-2`~`n3-4` 는 활동지 version2 의 SVG(6쪽)에서 잘라 선명하게 다듬은 것, `n4-*` 는 지금 사이트 화면을 새로 찍은 것입니다.
- 그림 자리를 늘리거나 줄이려면 `worksheet/lessons.js` 의 `type: "guide"` 묶음에서 `steps` 를 고칩니다. `img` 가 이 폴더의 파일 이름(확장자 빼고)입니다.
- 그림이 없는 칸은 화면에서만 빈 칸으로 보이고, 인쇄물과 이미지 저장에는 나오지 않습니다.
